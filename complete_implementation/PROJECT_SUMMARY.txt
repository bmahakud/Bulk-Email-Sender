================================================================================
                          SETUP REQUIREMENTS
================================================================================

1. PREREQUISITES
   - Python 3.12 or higher
   - Microsoft Azure account (free tier OK)
   - Outlook/Hotmail account(s)

2. AZURE APP REGISTRATION (5 minutes)
   - Create App Registration in Azure Portal
   - Get Application (client) ID
   - Add API permissions:
     * Mail.Send
     * User.Read
     * offline_access
   - Set redirect URI: http://localhost:8000/callback

3. INSTALLATION
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt
   $ cp .env.example .env
   (Edit .env with your CLIENT_ID)

4. RUN
   $ python app.py

================================================================================
                          SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

1. "Authentication failed"
   → Check CLIENT_ID in .env
   → Verify redirect URI

2. "No active accounts"
   → Add account in Accounts tab

3. "Rate limit exceeded"
   → Normal! Software auto-switches accounts
   → Add more accounts or increase delay

4. "Module not found"
   → Activate venv: source venv/bin/activate
   → Install: pip install -r requirements.txt

Debug Resources:
- Application logs: logs/app_YYYY-MM-DD.log
- Send logs: Logs tab in UI
- Database: database/database.db
